# Course blueprint

Import this folder from **Create Workspace → Import blueprint folder**. It is a
portable example: `template.json` declares the host-owned intake flow and
`skills/syllabus-intake/SKILL.md` supplies only the reviewed extraction prompt.

At creation, enter an optional syllabus link and term. The link is displayed in
the Course materials setup step but Ori does not fetch it until you accept the
host consent statement. Add files or select the course-materials folder there,
review the bundled skill, then review every proposed ticket, memory, note, and
calendar event before applying it.

The example is not an embedded starter. Importing it copies it into your own
template library; its source declarations remain inert and cannot run commands,
choose a model, or create records without your review.
