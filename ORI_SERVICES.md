# Ori Token and Marketplace Services

This repository provides the open-source Ori Agent core. It does not include
Ori Token issuance, marketplace payments, daily credits, cashout flows, or
anti-cheat enforcement services.

Access to Ori Token and marketplace services requires a separate agreement.
No private service endpoints, keys, or credentials are distributed here.

We do not provide guidance or support for third-party web3 implementations.

If you want to access Ori services, contact the Ori team.
