# Premium Features Proposal (Local-First)

This document captures a proposed Free / Pro / Pro+ tiering plan for Ori Agent,
focused on individual power users and fully local usage (no cloud dependency).

## Target Audience

- Individual power users
- Fully local usage only

## Tier Plan

### Free

- Core agent creation + multi-provider support
- Sessions with basic search, tags, folders
- Plugin system + YAML tool definitions
- Manual runs + basic scheduling (if present)
- Token-based plugin economy:
  - Tokens required for paid plugins
  - Free token allotment + optional token purchases
  - Per-plugin one-time unlocks pay developers

### Pro (Power User)

- Advanced automation: cron presets, conditional branches, retries, notifications
- Power sessions: semantic search, bulk tagging, smart archive rules
- Local usage/cost analytics + budgets
- Secrets vault with per-plugin scopes + audit log
- UI power tools: keyboard navigation, multi-pane, agent presets
- Includes monthly tokens for premium plugins

### Pro+ (Heavy Usage)

- Local backups + encrypted export/restore
- Local model management: profiles, performance tuning, per-agent routing
- Plugin quality tools: sandboxing + local signing/verification
- Priority local diagnostics + performance reports
- Includes higher monthly token allotment

## Pricing Options (Local-First)

### Option 1: One-Time License

- Pro: $49–79
- Pro+: $99–149
- Optional annual upgrade: $19–39 for major updates

### Option 2: Subscription per Device

- Pro: $6–10/month
- Pro+: $12–18/month
- Annual discounts: 15–25%

## Tokenomics (All Users)

- Applies to all tiers (free + paid).
- Payout model: per-plugin one-time unlocks.
- Free tier tokens: free allotment + optional token purchases.
- Pro/Pro+: include bundled monthly tokens (Pro+ higher).
- Ledger: open to local-only or light central ledger based on implementation.

## Web3 Wallet Adoption Enhancements

Goal: increase user adoption of token wallets by tying wallet usage to clear,
local-first value in Ori Agent.

- Guided wallet onboarding with security education (seed phrase, testnet first).
- Wallet-based identity for plugin purchases and portable licenses.
- Token utility: plugin unlocks, developer tips, staking for discounts.
- Wallet dashboard: balances, spend history, and value received per plugin.
- Funding flow: on-ramp links or QR invoices (optional if a light cloud service is allowed).
- Security options: hardware wallet support, export keys, read-only monitoring.
