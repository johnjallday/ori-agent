# Ori–Herdr Devflow Bridge

The operating guide moved to `docs/herdr-devflow.md` in the selected external
**Ori devtools** source. This page is a compatibility link, not a second manual.
Read [source selection and recovery](devtools.md), then the matching companion
guide. Existing Ori `wt` / DevOps command paths remain available.

## Setup

Resolve the operating skill with `bash scripts/devtools-setup-skill.sh` and read
that file. Selecting source is not permission to install or refresh runtime.

## Starting a feature

Work stays in one Ori feature worktree. Ori retains `.herdr/devflow.toml`, tasks,
project adapters and its canonical task-planning skill. The external guide owns
agent selection, handoff and retry details.

## One-time continuations

Existing stable runtime identities/argv are unchanged. Read the companion guide;
never duplicate a schedule merely because source selection changed.

## Overnight Runs

Unattended operation requires explicit intent and verified capabilities. Offline
extraction tests are not evidence of live agent/wake readiness.

## Guarded cleanup

Do not bypass known active agents, occupied tabs or unresolved schedules.
Missing source/config is not proof of an empty bridge. Use the reviewed recovery
path in `docs/devtools.md`; do not reset state to make cleanup succeed.
